# Thinkingオンでもログがない理由

モデルが返した思考チャンネルだけを表示します。Thinkingオンという設定だけからログを作ることはありません。
MAXでは計画・実装・検証・構造化JSONの生成も思考オンです。ゼロではオフ、自動では役割や依頼内容で判断します。MAXでもモデルが出力上限に達した場合や生成に失敗した場合は、思考や回答が未完了になることがあります。
思考ログは受信できた分から表示します。モデルが途中の思考チャンネルを公開しない場合は、受信前の内容を表示できません。その間は同じ欄のOLCR処理状況で、接続中のモデルやフォールバック、待ち時間を確認できます。
通常回答でモデルがログを返しているのに表示されない場合は表示経路の問題が考えられます。モデル名、用途、発生した回答を確認すると切り分けできます。
