# Editing messages and stopping generation

Press ■ at the right of the composer to stop generation, then send the next message.
Use the pencil icon on a sent user message to edit it. Cancel to abandon the edit.
The composer clears on successful submission. A failed submission may restore the draft for retry.
Follow-up coding instructions and edits to past messages have different targets. State new conditions as a follow-up when they should steer current work.
