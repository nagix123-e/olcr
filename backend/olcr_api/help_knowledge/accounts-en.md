# Connecting API accounts

Open Settings → Models → Providers.
For API key providers, choose Configure or Edit and save the key, base URL, and required model IDs. Keys are stored in macOS Keychain.
For ChatGPT, choose Continue with ChatGPT and complete browser sign-in.
Expand Accounts and priority and choose Add account to configure an empty slot. Each provider has up to three slots; use ↑ and ↓ to reorder them.
If a slot requires reconnection, use its reconnect button to sign in again.

Ollama Cloud is separate from local Ollama. Open Settings → Models → Providers → Ollama Cloud to register an API key. The default base URL is https://ollama.com/v1; leave model IDs blank for discovery. Keys are stored in Keychain, with up to three accounts in priority order. Enable external access for cloud requests. Select Ollama Cloud in the chat Brain picker to choose a model.
