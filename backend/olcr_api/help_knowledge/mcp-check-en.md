# Checking MCP connections

Opening MCP connections in Settings checks unverified servers in order. Missing dedicated environments download on first use and are kept on this Mac. Choose Check connection to retry a server. OLCR tests initialization and tool discovery without a model, then closes the connection. This does not execute tools or authorize automatic use. The UI distinguishes policy-disabled, missing runtime/server, timeout and missing-required-tool conditions. Inspect the reported reason rather than treating Connected as an executed action.
