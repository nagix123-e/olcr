# 長い会話・YaRN・自動圧縮

「設定」→「モデル」のローカルモデルのコンテキストで長さを調整します。YaRNと自動圧縮のオン・オフは「チャットで使う機能」です。
YaRNはMLX版Ornith・Bonsaiの対応するテキスト推論が対象です。Ollama APIからYaRNは変更できないため、Ollama使用時はオフにしてください。
自動圧縮は応答分を含む推定使用量が80%に達すると古い会話や参考資料を抜粋します。元の会話、現在の入力、必須指示は保持します。外部APIにはこのローカル設定を適用しません。
長くするとメモリ・時間・品質へ影響する場合があります。トークン数は文字数と同じではありません。
