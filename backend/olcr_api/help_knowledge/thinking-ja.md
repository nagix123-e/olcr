# Thinkingとログ

入力欄の「Brain」からローカルモデルのスライダーをゼロ・自動・MAXに切り替えます。ゼロは思考オフ、自動はタスクの役割や依頼内容に応じて判断、MAXは内部のOFF指定より優先して常に思考オンです。
モデルが思考チャンネルを返すと、回答の「思考ログ」を開いて確認できます。モデルから届いた生の思考ログと、区別して示したOLCRの処理状況を表示します。
計画・実装・検証や構造化JSONの生成でもMAXを適用します。MLXでは思考終了後にJSON制約を適用し、実際に届いた思考ログと実行用JSONを分けて扱います。短い検算・証明・不具合分析も自動判定の対象です。モデルや接続の失敗、出力上限に達した場合は、思考や回答が完了しないことがあります。
Ollama・MLXから届いた思考出力や、APIから実際に届いた思考要約は受信中から順次表示します。モデル読み込み、接続中、フォールバック、接続失敗と切り替え理由、最終ログからの待ち時間も同じ欄に表示します。スクロールで過去の行を読んでいる間は表示位置を保ちます。

Thinkingのオン／オフに対応するAPIモデル（Gemini 2.5 Flash / Flash-Lite、対応するClaudeの手動Thinkingモデル）にもゼロ・自動・MAXを使えます。APIのネイティブ設定で切り替え、深度指定に対応するモデルは従来の推論強度を使います。未対応のモデルにはオン／オフ設定を表示しません。
