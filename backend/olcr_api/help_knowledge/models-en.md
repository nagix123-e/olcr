# Choosing models

Open Brain in the composer, then click a role’s model name to select a provider and model.
The roles are Coding, Simple coding and fixes, and Inference. Settings → Models also offers separate roles or a unified model.
Choose installed local models or models from connected APIs. Missing models are not silently downloaded.
Adjust supported effort levels with the slider. Changes apply to the next request.
Configure model fallback order in Settings → Models. Accounts for the same model are tried by priority before replacement models.

Ordinary conversation and answers use the Inference selection. Implementation uses Coding, while small code changes use Simple coding and fixes.
