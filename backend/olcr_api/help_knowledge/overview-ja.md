# OLCRの使い方

入力欄に依頼を書き、↑を押して送信します。回答生成中は同じ場所の■で停止できます。
設定は右上の「設定」、モデルの選択は入力欄の「Brain」から開きます。
「設定を開いて」「タイマーを5分」「YouTubeで動画を検索して」のようにチャットで操作を依頼できます。
プロジェクトを選ぶと作業フォルダーに関連付けられます。通常の質問やカスタムエージェントはプロジェクトなしでも使えます。
モデル、アカウント、音声入力、読み上げ、思考ログ、Quick、エージェント、Skills、GitHub、カレンダー、動画、タイマー、コーディングの再開について個別に質問できます。
接続・再生・保存などが実行済みかどうかは、実際の結果表示で確認してください。
