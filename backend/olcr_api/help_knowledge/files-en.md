# Attachments and file links

Use + in the composer to attach a file and state whether to read, extract, or convert it. Images use a compatible vision model.
Specify an output format, such as “Convert this to CSV”, and a destination folder when needed.
Click a file link in an answer to open it with its Mac application. Paths with spaces and separate files are handled individually.
If opening fails, check that the file was actually created and that its path is correct.

Sent attachments clear from the composer when submission starts. Sent images appear inline for 24 hours, including when reopening the conversation. After 24 hours they are shown by filename only.

You can attach an audio file too. Include “transcribe this” to start using the transcription model configured for the current UI language. Sending only the file asks for confirmation: reply “yes” to start or “no” to cancel. Pending audio is kept for up to 24 hours so you do not need to attach it again. Files are limited to 50 MB and one hour; longer recordings within that limit are transcribed in segments.
