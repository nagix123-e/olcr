# Using OLCR

Type a request and press ↑ to send it. During generation, press ■ in the same position to stop.
Open Settings at the upper right. Open Brain in the composer to choose models.
Ask in chat, for example: “Open Settings”, “Set a timer for five minutes”, or “Search YouTube for a video”.
Projects associate work with a folder. Ordinary questions and custom agents also work without a project.
Ask separately about models, accounts, voice input, read aloud, thinking logs, Quick, agents, Skills, GitHub, calendars, videos, timers, or resuming coding.
Check the actual result before assuming a connection, playback, or save completed.
