# Voice input

When the composer is empty, press its waveform button to start recording. Press Stop again to stop; recognized text appears in the composer. Press ↑ to send.
When text is present, the button becomes the send arrow.
Settings lets you choose local LFM or macOS transcription. Grant microphone and speech recognition permissions for macOS transcription.
LFM uses LFM2.5-Audio-1.5B-JP for Japanese and LFM2.5-Audio-1.5B for English. Accept the first-use download prompt if needed.
Use the Hands-free mode toggle for continuous voice operation. Received transcript segments appear progressively.
