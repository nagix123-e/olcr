# APIアカウントの接続・追加

「設定」→「モデル」→「接続先」でプロバイダーを選びます。
APIキー方式では「設定」または「編集」からキー、ベースURL、必要なモデルIDを保存します。キーはMacのキーチェーンに保存します。
ChatGPTは「ChatGPTで続行」からブラウザで認証します。通常のAPIキーを入力する方式とは異なります。
「アカウントと優先順位」を開き「＋ アカウントを追加」で空き枠を設定します。各プロバイダーは最大3枠です。↑↓で優先順位を変更できます。
再接続が必要と表示された場合は、その枠の再接続ボタンから認証し直します。

Ollama CloudはローカルのOllamaとは別の接続先です。設定→モデル→接続先→Ollama CloudからAPIキーを登録します。標準のAPIベースURLは https://ollama.com/v1 で、モデルIDは空欄でも自動取得します。キーはKeychainに保存され、最大3アカウントの優先順位を設定できます。クラウド利用には外部アクセスを許可してください。チャットのBrainからOllama Cloudを選んでモデルを指定します。
