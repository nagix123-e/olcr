# 添付ファイルとファイルリンク

入力欄の＋からファイルを添付し、読み取りや変換などの目的を書いて送信します。画像は対応する画像理解モデルで認識します。
「CSVに変換して」のように出力形式を指定できます。保存先が必要な場合は対象フォルダーも指定します。
回答に表示されるファイルリンクを押すと、Macの対応アプリで開きます。空白を含むパスや複数の別ファイルも個別のリンクとして扱います。
開けない場合は、ファイルが実際に生成済みか、保存先のパスが正しいかを確認します。

送信した添付ファイルは送信開始時に入力欄から消えます。送信済み画像は24時間、会話内にプレビュー表示します。会話を開き直しても期限内は画像を表示し、24時間後はファイル名だけに切り替わります。

音声ファイルも添付できます。「文字起こしして」と添えて送ると、言語設定に対応する「文字起こし」のモデル設定で実行します。音声ファイルだけなら実行を確認し、「はい」で開始、「いいえ」で取り消します。確認待ちの音声は最大24時間保持され、再添付せずに実行できます。1ファイル50 MB・1時間までで、長い音声は分割して文字起こしします。
