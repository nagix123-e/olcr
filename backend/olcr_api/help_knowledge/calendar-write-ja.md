# 予定の書き込みと確認

追加・変更・削除はチャットで対象の予定と日時を指定し、提案された内容を確認して反映します。曖昧な対象は名前・日時・カレンダー名を補ってください。
接続・読み取りができても、そのカレンダーへの書き込みが許されるとは限りません。読み取り専用や共有権限を確認します。
削除や変更が完了したかは実際のアクション結果で確認してください。依頼文だけを実行済みとは扱いません。

追加項目は「明日8時に『面談』を登録、場所: 会議室A、メモ: 資料を持参、通話URL: https://example.com/room、カレンダー: 職場」のように、読点または改行で区切って指定します。場所・メモ・URLは確認画面で修正できます。保存先カレンダーは書き込み可能な名前に一致するものを使い、見つからない・同名が複数ある場合は登録しません。既存の通話URLは保存できますが、会議室URLの発行、招待者追加、ファイルのネイティブ添付は未対応です。これらを指定した場合は未対応と返し、登録を完了したとは表示しません。
