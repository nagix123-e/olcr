# Macのカレンダー接続

「設定」→「カレンダー」の「カレンダーに接続」を押します。Macのカレンダーを利用し、APIキーやGoogleの開発者設定は不要です。
macOSの確認画面でOLCRのカレンダーアクセスを許可してください。拒否した場合はシステム設定→プライバシーとセキュリティ→カレンダーで見直します。
接続後は「明日の予定を見せて」「金曜15時に打ち合わせを追加して」とチャットで依頼します。
予定の追加・変更・削除は提案内容を確認して反映します。読み取り専用のカレンダーには書き込めません。

「カレンダーに明日15時に『歯医者』を書き込んで」と依頼できます。チャットに出る予定の追加カードでタイトル・開始・終了を確認し、「この内容で登録」を押すか「はい」と返信すると、選択済みのMacの予定表に書き込みます。

「明日朝八時に『学校に行く』という予定を入れて」のような漢数字や朝・夜の表現にも対応します。終了時刻がなければ1時間後を提案し、確認カードに表示します。終日や開始・終了時刻の指定もできます。Macのカレンダーへの新規登録は、未接続でも確認カードから接続を進めます。初回はmacOSのアクセス許可が必要です。登録先は書き込み可能な予定表を自動選択します。
