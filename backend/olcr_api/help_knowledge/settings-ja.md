# 設定画面の開き方

右上の「設定」を押すか、チャットで「設定を開いて」と依頼します。
言語、音声入力、読み上げ、外部アクセス、GitHubやカレンダー接続などを設定できます。モデルの詳しい設定は「モデル」へ進みます。
モデルを日常的に選び直す場合は、設定画面を開かず入力欄の「Brain」から選べます。
設定画面の戻るボタンで元の画面へ戻ります。モデル変更は次のリクエストから適用されます。

「コーディングサブエージェント」はCoding Orchestratorとは別の設定で、初期状態はOFFです。ONにしても自動起動せず、重く独立した並列実装ができるCoding Taskで、ユーザーの明示指示またはタスク専用の追加承認があるときだけ利用します。有効化時には、ローカルモデルを推奨しないこと、役割遵守・結果統合の品質、応答時間、メモリ・計算資源に影響することを示す警告を確認してください。workerのモデルは現在のCoding Task実装モデルに固定されます。
