# YouTube search and playback

No YouTube connection setup or API key is needed. Enable external access and ask “Search YouTube for …” or “Show the latest videos from …”.
Top results appear as thumbnails. Choose one to start the internal player, or supply a video URL directly.
Choose Play fullscreen to expand, then Back to OLCR or Esc to return to the internal player.
If autoplay is blocked, press Play inside the player. Use Open on YouTube for videos that disallow embedding.
