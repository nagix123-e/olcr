# コーディングカードを閉じた後の再開

カードを閉じても保存済みコーディングタスクは削除しません。同じ会話で「再開」と送ると保存状態から戻れます。
完了工程、現在の工程、失敗記録、承認済み範囲を使って続行します。閉じたことは工程の成功・完了を意味しません。
別の会話で新しいタスクを作ると元のタスクとは別扱いになります。元の履歴を開いて再開してください。

タスクカードは計画中から表示します。使用モデル欄には実際に呼び出したモデル名とAPI／ローカルの区別を表示します。計画・推論とコーディングでモデルが異なる場合、コーディングモデルの呼び出しは計画後に始まります。接続失敗や切り替えは保存記録で確認できます。モデルから受け取っていない思考ログは生成しません。
