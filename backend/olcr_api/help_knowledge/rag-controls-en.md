# Retrieval relevance controls

Under Settings → Models → RAG and context, adjust supplemental context allowance, relevance threshold and model-specific allowances. Graphify, search results and history are selected for relevance to the current request; even recent history may be excluded. More context can increase latency and memory. Changes apply to the next request. OLCR operation help has its own bundled knowledge route and works without a project or external model.
