# 画像付きエージェントが失敗するとき

添付画像の読み取り、回答モデルの生成、会話への保存を別々に確認します。回答生成に成功しても保存失敗なら会話に回答が残らないことがあります。
画像入力はPNG・JPEG・WebP、画像データは5MB以下が対象です。認識用モデルの画像対応・接続状態も確認してください。
AGENT_RESPONSE_SAVE_FAILEDは回答の保存失敗、AGENT_IMAGE_PROCESSING_FAILEDは画像処理段階の失敗を示します。発生時のモデル・用途・エラーを控えると切り分けできます。
保存DBの互換性修正は更新版の起動時に適用します。未確認の画像内容を推測して回答したとは扱いません。
