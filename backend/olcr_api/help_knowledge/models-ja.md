# モデルの選択

入力欄の「Brain」を開き、用途カードのモデル名からプロバイダーとモデルを選びます。
用途はコーディング、単純なコーディング・修正、推論です。「設定」→「モデル」では用途別またはひとつに統合を選べます。
利用可能なインストール済みローカルモデルと、接続したAPIのモデルを選択できます。未導入モデルを勝手に取得して使うことはありません。
同じカードのスライダーで対応する推論強度を変更します。変更は次のリクエストから適用されます。
モデルのフォールバックは「設定」→「モデル」で順序を指定します。まず同一モデルのアカウントを優先順で試し、その後に代替モデルを試します。

通常の会話や質問への回答は「推論」の設定を使います。実装は「コーディング」、短いコード修正は「単純なコーディング・修正」を使います。
