# Mac Calendar connection

Choose Connect calendar under Settings → Calendar. OLCR uses Mac Calendar; no API key or Google developer setup is required.
Allow OLCR calendar access in the macOS prompt. If denied, review System Settings → Privacy & Security → Calendars.
Then ask “Show tomorrow’s events” or “Add a meeting on Friday at 3 PM”.
Review proposed event additions, changes, and deletions before applying them. Read-only calendars cannot be modified.

Ask “Add an event tomorrow at 15:00 called "Dentist" to my calendar”. Review its title, start, and end in the chat preview, then choose “Add this event” or reply “yes” to write it to the selected Mac calendar.

Calendar requests accept Japanese numeral times, morning/evening, explicit time ranges, and all-day events. When no end time is supplied, the preview proposes one hour. Confirming a new event can connect to Mac Calendar directly; macOS permission is required on first use. OLCR automatically selects a writable calendar.
