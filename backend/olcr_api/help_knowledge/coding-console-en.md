# Resuming after closing the coding card

Closing the coding card does not delete the saved task. Send Resume in the same conversation to continue from its saved phases, failures and approved scope. Closing the card does not mark work complete. A new task in another conversation is separate; reopen the original conversation to resume it.

The task card is visible while planning. It shows the model actually invoked and whether it runs locally or through an API. Planning and implementation may use different selected models; the implementation call starts after planning. Invocation and failure records are saved. Thought logs are shown only when actually received from the model.
