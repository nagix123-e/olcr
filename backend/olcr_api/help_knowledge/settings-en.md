# Opening Settings

Click Settings at the upper right, or ask “Open Settings” in chat.
Configure language, voice input, read aloud, external access, and GitHub or Calendar connections. Open Models for detailed model configuration.
For everyday model selection, use Brain in the composer without opening Settings.
Use Back to return. Model changes apply to the next request.

“Coding subagents” is a separate setting from Coding Orchestrator and defaults to OFF. Enabling it never starts workers automatically; they are available only for a heavy Coding Task with independent parallel implementation work and a direct user instruction or separate task-specific approval. Enabling the setting requires acknowledgement that local models are not recommended and that role adherence/synthesis quality, latency, and memory/compute load may be affected. Workers are pinned to the current Coding Task implementation model.
