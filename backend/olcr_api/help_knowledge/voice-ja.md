# 音声入力

入力欄が空のとき、右側の波形ボタンで録音を開始します。もう一度停止ボタンを押すと録音を止め、認識した文章を入力欄に入れます。↑で送信します。
文字が入力されていると右側は送信↑になります。
設定で文字起こし方式を選択できます。ローカルLFMとmacOSの文字起こしに対応します。macOS方式ではOSの音声認識・マイク権限を許可します。
LFMは日本語設定ならLFM2.5-Audio-1.5B-JP、英語設定ならLFM2.5-Audio-1.5Bです。未導入なら初回のダウンロード確認に同意して取得します。
「ハンズフリーモード」のトグルで連続した音声操作を切り替えます。認識中の文章は受信できた部分から入力欄へ反映されます。
