# Custom agents

Open Agents from More. Choose Create agent, configure its name, description, instructions, model, knowledge, tools, and skills, then save.
Add an icon image with the image picker or drag and drop.
Choose Use in the agent list to open its conversation. It defaults to no project. Back to chat returns to the original screen.
For an attached image, OLCR’s vision model reads it and the selected agent answers using that evidence. Unreadable text and unverified addresses remain uncertain.
Start a normal conversation to switch back from the agent.
