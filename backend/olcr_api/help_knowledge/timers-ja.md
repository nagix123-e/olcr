# タイマーとアラーム

チャットで「5分のタイマーをかけて」「1時間30分のタイマー」「明日午前7時半にアラームをかけて」「23:30にアラームを設定して」と依頼します。モデルの推論や外部APIは使わず、ローカルで登録します。
タイマーの残り時間はチャット内のカードにカウントダウン表示します。一時停止・再開・停止ができます。「タイマーを一覧で見せて」でも確認できます。
アラームは端末のタイムゾーンで指定時刻を解釈します。日付の指定がなければ次に来るその時刻（過ぎていれば翌日）です。設定時刻をカードに表示し、停止できます。アラームは時刻固定のため一時停止できません。「アラームを一覧で見せて」で確認できます。
タイマーは1秒から7日、アラームは7日先までの1回限りに対応します。複数ある場合はカードで対象を選ぶか、名前を付けて依頼してください。
初回はmacOSの通知許可を承認してください。拒否した場合はシステム設定→通知でOLCRを許可して戻ります。通知は音付きでmacOSに予約し、登録後はチャットを閉じたりOLCRを終了したりしてもmacOSが通知します。Macがスリープ中・電源オフの間の定刻表示は保証できません。
記録はローカルに保存します。カードに通知の登録確認中・登録失敗・許可なしが出た場合はその案内を確認してください。通知予約の成功は配信済みの意味ではありません。

直前に作ったアラームには「今日の六時」「午後」「明日にして」のように短く訂正できます。時刻が曖昧なら午前・午後や日付を確認し、同じアラームを変更します。停止・終了済みのアラームを勝手に再開しません。タイマーは「あと5分追加して」「10分にして」「名前は『お茶』にして」に対応し、一時停止中の長さ変更では停止状態を保ちます。「何時に設定した？」「あと何分？」も直前の対象について確認できます。
