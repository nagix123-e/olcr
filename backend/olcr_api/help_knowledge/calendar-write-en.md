# Calendar write review

Specify the event and time in chat, then review proposed additions, changes or deletions before applying. Clarify ambiguous names, times or calendars. Connection and read access do not imply write access; check read-only and sharing permissions. Confirm modifications from actual action results, not just the request text.

Optional fields can be supplied on separate lines: Location: Meeting room A; Notes: Bring documents; URL: https://example.com/room; Calendar: Work. Location, notes and URL remain editable in the confirmation form. Calendar names must uniquely match a writable calendar. Existing call URLs can be saved; meeting-link creation, invitations and native file attachments are not supported. These unsupported requests are reported rather than silently dropped.
