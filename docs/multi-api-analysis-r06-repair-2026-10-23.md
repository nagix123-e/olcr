# r06 GUI実行からの共通原因修正 — 2026-10-23

対象は除外後の32課題。課題の必要な対象が欠けていた18件は修正の評価対象に含めない。

## 確定した原因と変更

| 原因 | 変更 | 関連する旧ケースID |
|---|---|---|
| 全API失敗後に検索タスクへ切り替えると、APIの失敗実行記録と経路が消える | 早期リターンを含め全試行を記録。分析の外部API経路と検索による補完経路を両方保持。検索出典も呼出元へ返す | 07, 08, 12, 14, 19, 24, 28, 38, 40, 41ほか |
| 長い地域指定をIMF DataMapperのURLパスへ連結すると404 | 8か国を超える指定は期間を限定した指標取得に切り替え、返却された国コードをローカルで照合。欠落国を`missing_countries`と不完全な応答として記録 | 04 |
| 国名・地域・二国間貿易を混同 | 東南アジアを加盟国へ解決し、各報告国と世界の取引を共通条件で比較。不明な報告国を日本へ置き換えない。「日本から米国へ」などの明示指定は保持 | 03, 07, 24 |
| 日米欧の省略表記が通常の国名抽出で欠落 | 共通の地域解決で日本・米国・EUを保持 | 11 |
| 複合語「宇宙天気」から通常の気象APIまで要求 | 複合語を除いた残りの文に独立した気象要求がある場合のみ通常気象を追加 | 22 |
| 複数APIを使う依頼文をそのまま議事録・法令検索語にする | 各APIの言語に合わせた主題に分離。具体的な短い検索語や既存の固有名は優先して保持 | 37–42 |
| GitHubが既知リポジトリのリリース照会に限られる | 主題による公開リポジトリ検索を追加。指定されたリポジトリの既存リリース照会は維持。検索結果は全体の活動量の証明として扱わない | 48 |
| 要求した別指標がコンパイル時に落ちる | 既存World Bank経路で水ストレス、農業付加価値、開発指標、対外債務などを独立して生成。定義の違いを表示し、一般政府債務と対外債務や、生産量と電源構成比を同一視しない | 04, 21, 42など |
| EurostatのJSON-statが古い時期・一部の国から切り詰められる | 観測日・国・指標・単位を正規化し、各系列の新しい観測を順番に選んでから証拠量を制限 | 06 |
| 検索補完の本文が巨大・主題と無関係 | 国・期間・不足項目・一次ソースに寄せて検索し、本文は主題で選別。補完元は最大4件、本文合計はモデル用の設定コンテクスト予算内。省略を明記 | 部分取得がある全ケース |
| 補完検索の例外が成功したAPIデータまで破棄 | 補完を独立した任意処理とし、通信・モデル・不正応答の失敗後も成功した兄弟APIを保持 | 部分取得がある全ケース |
| 文書掲載日が「数値の欠測」として処理される | 実際の`value`フィールドがある行にだけ数値欠測処理を適用 | 37, 39, 42など |
| 推論失敗時に「統合できる数値系列なし」だけになる | 文書、議事録、リポジトリは題名・観測/掲載日・発言者・本文抜粋を出典付きで整理する決定的な経路を追加。数値は既存の検証済み計算を継続。任意の文章生成待ちは20秒に制限 | 非数値・混合データ全般 |

元のr06レポートの「RETRIEVALへ誤ルーティング」は仮説だった。ログには該当ケースでAPIの実行計画と通信が存在する。API失敗後の記録漏れにより、DBの経路・実行件数だけでは実行が分からなかった。この修正ではAPIを再試行する際の記録と出典の保持を直し、検索フォールバックそのものを禁止していない。
