# ローカルのウェイクとウェブカメラによる人間のハンズフリー入力

## 利用

チャットの「ハンズフリー」を開いてONにするか、`/handsfree on` または「ハンズフリーモードをオンにして」と送信する。OFFはパネルの停止ボタン、閉じるボタン、`/handsfree off`、またはウェイク後の「ハンズフリーオフ」で行う。通常のマイク入力と同時には開始しない。

初回ON時にだけlocal-wake・OpenCV・MediaPipeなどの任意ランタイムを取得する。今回のmacOS/arm64環境では約250 MBだった。LFM音声モデルがない場合は、選択言語のローカル音声モデル（現在の表示目安約3.7 GB）も取得する。パネルを開くだけ・通常起動・OFF・状態表示では取得しない。キャッシュ済みモデルは再利用する。

マイクの許可後、「OLCR」を普段の声で3秒ずつ3〜4回録音する。既定音声は同梱していない。別のウェイク語句にするには「録り直し・語句を変更」で登録を削除して語句を入力する。登録は最大6回。音声はアプリのプロファイル内だけに保存し、録り直しで削除する。

ウェイクを検出すると短い確認音を鳴らし、ウェイク判定を停止して同じマイク入力を指示の録音へ切り替える。指示は無音0.85秒で確定し、ローカルLFMで文字起こしして通常チャットへ送る。指示を話し始めるまでの上限は20秒。文字起こし・応答処理中はウェイク判定を行わない。編集中の草稿や添付がある場合は認識結果を草稿に追加し、自動送信を保留する。チャット応答のモデル選択は通常のBrain設定に従う。

デスクトップではカメラ入力も既定で選択される。音声だけ使う場合はON前にチェックを外せる。カメラ映像はブラウザの機器権限で取得し、認証済みのローカルAPI経由でOpenCVのデコード・左右反転・色変換とMediaPipeの手認識を行う。入力映像は保存しない。カメラ認識も任意に停止・再開できる。

- 人差し指を立てる：カーソル移動。
- 短い親指・人差し指のピンチ：クリック。
- ピンチを0.55秒以上保持：ドラッグ。解除または追跡ロストでボタンを離す。
- Vサインを上下に動かす：スクロール。
- 開いた手のひら：ジェスチャー入力の一時停止。保留中のクリックを取消す。

カメラはmacOSのカメラ許可、マイクはマイク許可、OSのカーソル操作はアクセシビリティ／イベント投稿許可が必要。スクリーンキャプチャを起動する必要はない。

## 実装の境界

人間の入力を扱う機能であり、エージェントのComputer Useの対象認識・計画・実行APIとは別経路。`desktop/src-tauri/src/human_input.rs`が専用の短命トークンと単調増加シーケンスでOS入力を受ける。800 ms以上古いフレーム、将来時刻、再送、範囲外座標を拒否する。フレーム到着が1.2秒途絶えた場合もドラッグを解除する。入力先のディスプレイはジェスチャー開始時のカーソル位置から選ぶ。

`backend/olcr_api/handsfree.py`はOFFの状態で生成される軽量な管理器。初回ONでアプリの主Python環境を変更しない専用venvを用意し、PyPIの解決レポートに記載されたSHA-256でwheelを検証してからローカルwheelをインストールする。Gesture Recognizerのモデルにも固定SHA-256を指定する。以後のONでpipの再インストールやモデルの再取得を行わない。バージョン固定と完了マーカーで取得を管理する。将来ランタイムの互換条件を変更する場合はPACK_VERSIONを更新する。

`handsfree_worker.py`だけが任意のMLライブラリを読み込む。local-wake 0.1.2のspeech embeddingとDTWを使い、登録サンプル同士の距離から閾値を調整する。登録・検出で同じ音声トリミングを適用し、無音マージンによる検出失敗を抑える。OpenCVとMediaPipeの認識結果は純粋な`GestureInput`状態機械へ渡す。

ブラウザ側は単一のマイクストリームを持ち、ウェイク・指示録音・文字起こし・応答待機を排他的に切り替える。OFF／アンマウント／言語変更でマイク・カメラを解放し、非同期の古い結果を捨てる。サーバー側にも20秒のリースがあり、UIが失われた場合はワーカーを止める。初回取得中のOFFは次の取得・インストールを抑止し、進行中の子プロセスを終了する。

## 検証済みと未検証

- オプションパックの実取得、local-wake・MediaPipeの実起動、取得済み状態での追加ダウンロードなしの再ONを確認。
- local-wake公式の公開録音3件を隔離プロファイルに登録し、正例検出・雑音の非検出・前後の無音付き正例を確認。これらを既定のOLCR用サンプルとして同梱・登録していない。
- MediaPipe公式のPointing Up画像から移動イベントを取得し、Thumb Up画像が移動イベントを生成しないことを確認。
- フロントエンド23件、API50件、ハンズフリー／ジェスチャー8件、ネイティブのフレーム拒否1件が成功。TypeScriptとフロントエンド製品ビルドも成功。
- ユーザーの声によるOLCR登録、実マイク入力、実ウェブカメラからのカーソル操作は未検証。ユーザーの指示により実GUI検証は停止し、既存のOLCRを起動・操作・終了していない。
