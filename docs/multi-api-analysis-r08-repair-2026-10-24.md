# r08実GUI実行で見つかった問題への修正

2026-10-24 JST。対象は [r08の32課題・同一会話GUI実行](multi-api-analysis-gui-e2e-2026-10-24-r08.md) で観測した失敗。ケース固有の回答を埋め込まず、引数コンパイル、証拠の完全性、Web補完、表示量、最終推論の各境界を修正した。元の役割別Brain選択・設定済みモデルフォールバック順序は変更していない。

## 原因と変更

| 共通原因 | 修正 |
|---|---|
| APIの検索欄へ日本語の複合依頼全体を渡し、対象語として扱っていた | 臨床試験は疾患・対象国を分離。一般的な国別動向では疾患を捏造しない。HDXは地域・国名へ正規化。制裁一覧比較は対象名検索と区別し、空検索語を保持。 |
| 為替の引数コンパイル不足、日本語と隣接するISO通貨コードの認識不良 | 基準通貨・相手通貨・期間を別々に抽出。日本の為替ならJPYを使用。相手通貨未指定では提供元の公表パネルを使い、USDを勝手に代表値にしない。既存の明示ペア換算経路を保持。履歴は月次集約と表示。 |
| 提供元の別機能を必要とする依頼を未対応としていた | 英国審議はHansardのdebate検索、カナダ審議は発言APIへ分離。既存の法案・議員検索は保持。ブラジル地域開発はポルトガル語の主題検索を追加。 |
| 廃止・不適切な指標を選択していた | World Bankの現行GHG系列を使用し、CO2のみと温室効果ガス全体を区別。米国発電はEIAの燃料別発電量へルーティング。 |
| 政府契約額と政府支出の区別が不足 | 連邦政府の一般的な支出照会はSpending Explorerの会計年度別obligations（支出義務額）を取得。現金の実支出額outlaysとは明示的に区別し、実支出要求や未完了年度を完全取得扱いにしない。既存の契約・受注者検索を保持。 |
| 大きな正規化前レコードが後続レコードを押し出す | HDXは題名・説明・更新日・提供元・ダウンロード先を持つコンパクトなカタログへ正規化。EIAは分析用の全数値行を保持し、表示用の行数制限と分離。 |
| 一部取得や別粒度のデータを要求全体の充足と誤認 | HDXカタログ、議会・臨床試験・制裁リストの抜粋を部分取得と明示。年次PM2.5は季節分析を満たさず、発電総量だけでは構成を満たさない。EIAは要求期間のALL燃料観測が揃うか確認。複数年の要約も最初の一年だけへ切り詰めず、指定した年の全観測を使う。 |
| 対象地域を地点APIへ無理に押し込む | 米国全域・欧州全域を任意の一都市に置き換えない。未対応の粒度は能力不足として不足軸の補完へ渡す。 |
| 英語の一次資料を日本語の質問に無関係と判定 | Web補完に二言語の主題語を使用。国・地域の不一致は引き続き拒否。既存APIの本文フィルターは狭い主題判定を保持し、Web向け拡張を全APIへ波及させない。 |
| 複数の不足軸を一つの検索に混ぜる／一軸の失敗で補完を終了 | 不足軸ごとに最大4クエリへ分割。電力アクセス率など個別の不足指標を検索語へ保持。一つの検索が失敗しても後続を実行し、得られた出典・実行記録を最終回答へ保持。 |
| API証拠表示が5万〜11万文字へ肥大化 | 分析用データは保持し、表示用コピーを系列・地域ごとに抽出。モデルのコンテクスト設定に基づく上限で証拠・本文を制限。重複したrawデータを表示から除き、数値行や末尾の留保を保って省略。 |
| 全滅時の推論が長く反復し116〜316秒待機 | 最終推論は設定済み推論Brainと既存フォールバック経路を使用し、thinkingを無効、生成上限384 tokens、短い回答を指示。反復文も抑制。推論だけの回答には未検証の留保を保持。チェーン全体を早期打ち切る期限は追加していない。 |
| GitHubの認証エラーとレート制限を混同 | 403のレート制限ヘッダーを分類。保存トークンによる認証拒否のみ公開検索を一度試行し、レート制限では再試行しない。 |
| UNHCRの有効な正規化数値を表示できない | country/year/indicator/value形式と出身国・受入国の軸を読み取り、難民・庇護申請者・国内避難民を区別。 |

Spending Explorerのobligationsとoutlaysの区別は [米財務省の定義](https://fiscaldata.treasury.gov/americas-finance-guide/federal-spending/) と [USAspending API契約](https://github.com/fedspendingtransparency/usaspending-api/blob/master/usaspending_api/api_contracts/contracts/v2/spending.md) に基づく。為替履歴の月次集約は [Frankfurter公式仕様](https://frankfurter.dev/) に従う。

## 実API通信

モックを使わず、修正した11系統の公開APIアダプターを実行し、全てでDATA応答を取得した。通信・解析に失敗したチェックは修正後に再実行し、最新結果を記録した。これは11系統の通信確認であり、32課題の分析完遂やGUIの再合格を意味しない。

| 系統 | 最新結果の行数 | 取得範囲 |
|---|---:|---|
| Frankfurter | 3 | 明示した期間・JPY/USDの月次参照レート |
| World Bank GHG | 1 | 日本の指定年・全GHG系列 |
| ClinicalTrials.gov | 5 | 英国の試験サンプル。全件動向ではない |
| 英国Hansard | 5 | 医療に関する審議検索サンプル |
| カナダ議会 | 5 | 発言サンプル。全国政策の網羅集計ではない |
| USAspending | 1 | FY2024のobligations。outlaysではない |
| EIA発電量 | 156 | 2024年12か月×13燃料区分。量であり構成百分率ではない |
| HDX | 5 | ウクライナのデータセット書誌・取得先。数値分析の完了ではない |
| 国連制裁 | 5 | 一覧のサンプル |
| 米国OFAC制裁 | 5 | 一覧のサンプル |
| GitHub | 5 | 公開リポジトリ検索サンプル |

秘密の認証値を読み出したり記録したりしていない。EIA検証は公式の公開DEMO_KEYをプロセス内で使用。安全なメタデータのみを [実通信結果JSON](multi-api-analysis-r08-repair-live-2026-10-24.json) に保存した。`request_complete` はそのAPIに渡した要求の充足を示し、分析課題全体の充足ではない。

## 回帰テスト

各スイートは重複するテストを含むため、件数を合算しない。Pythonはリポジトリの `.venv312/bin/python`、`PYTHONPATH=backend:backend/tests` を使用。

| 最終確認したスイート | 結果 |
|---|---|
| `test_analysis_r08_repair.ProviderContractTests` + `EvidencePresentationTests` + `test_argument_compiler` + `test_external_api_expansion` | 143件実行、136件合格・7件スキップ |
| `test_analysis_r08_repair` + `test_analysis_pipeline_contract` | 43件、全件合格。32課題の必要ソース保持、現在パケットだけでの合成、不足指標補完、表示量、留保付き推論などを確認 |
| 最終のEIA複数年・季節集計変更を含む `test_analysis_r08_repair.EvidencePresentationTests` | 6件、全件合格 |
| `test_analysis_evidence_quality.EvidenceQualityTests` + `test_analysis_r06_repair.RecoveryContextBudgetTests` | 21件、全件合格 |
| `test_brain_fallback_order` | 10件、全件合格。現在の各役割のモデル開始・共有フォールバック順・モデルごとの文脈上限を保持 |
| 変更したPythonモジュールの `py_compile`、対象ファイルの `git diff --check` | 合格 |

途中で落ちた旧契約の期待値も検証した。旧CO2系列、EIA発電未対応、米国発電をWorld Bankへ送る期待値は、今回実通信で確認した現行系列・EIA機能に合わせて更新。電力アクセス率を電源構成検索にしていた件は期待値だけの変更で済ませず、不足指標の検索語生成そのものを修正した。43件の分析経路テストはその修正後に通過している。

今回追加した回帰テストは `backend/tests/test_analysis_r08_repair.py`。生の観測500行を保持したまま表示を4,500文字未満に抑えるケース、一つの補完が失敗しても他の軸と出典を残すケース、取得途中の年度を完全取得扱いにしないケースを含む。

## 検証の限界

この修正後の32課題実GUI E2Eは未実行。開いていたr08専用GUIは修正前のコードを読み込んだままであり、最新コードで起動したとは扱わない。

提供元に存在しない粒度、権限、未公表期間、全件を取得していない資料は、取得成功に見せかけず不足として残す。OpenSkyから過去の地域別観光回復統計を作ることや、地点の現在値から国全体の季節的大気傾向を導くことはしていない。これらは改善した不足軸別Web補完を経て、必要なら留保付き推論へ進む。モデル実行速度そのものや外部APIの将来の可用性は保証しない。
