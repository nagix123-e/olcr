# Reusable agent tools

通常の操作は[チャットからの指示](chat-personal-workflows.md)で行えます。タスク・目標・プロフィール・フォーム・ツールを起動するために設定画面へ移動する必要はありません。

チャットで目的を文章で伝えると、必要な入力を聞き取り、ツール案を提示します。内容を確認して保存でき、JSON定義の直接編集は不要です。保存後は名前と入力を同じチャットで指定して実行でき、カスタムエージェントの「ツール」からも選択できます。

この機能は既存の読み取りAPI・計算・データ処理ツールを最大8ステップで組み合わせます。入力値は `${inputs.name}`、先行ステップの結果は `${steps.0.result}` のようにJSON文字列全体で参照します。入力型・ツールID・前方参照を検査し、実行時は各既存ツールの引数検証とアクセス権限を再確認します。無効化した定義は実行できません。保存済み定義は変更せず、変更時は新しいツールとして保存します。

生成したコード・シェル・ファイル書き込み・送信・購入処理をホストへ直接登録する機能ではありません。具体的なAPI引数は利用先の契約に従う必要があり、モデルが生成した定義を保存しても実データ取得の成功を保証しません。一般的なプログラムの生成・検証は既存のCoding Task機能を使います。
