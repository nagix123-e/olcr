# RAG選別・API分析ルーティングの共通修正（2026-10-21）

## 設定

Settings → Models → **RAG・コンテクスト** に次を追加した。

- 追加コンテクストの上限目安：既定8,000文字、256〜200,000文字。入力文・必須指示とは別の、追加情報の予算。
- 関連性のしきい値：既定0.55。大きいほど厳選する。Graphifyの候補、保存会話メモリ、通常の会話コンテクスト選択に適用。
- モデル別の追加コンテクスト予算：未指定は共通設定を継承。現在の役割が選んだモデルIDを使い、フォールバック先のモデルにも個別予算を適用する。

`PATCH /api/settings/retrieval` で対象フィールドだけを保存する。古い設定画面のスナップショットで権限や他の設定を上書きしない。文字数はトークン数やモデルの最大ウィンドウの保証ではない。

## 共通原因と修正

| 観測された症状 | コードから確認した原因と修正 |
|---|---|
| 関連の薄い直近の会話が入る | 直近8メッセージをそのまま投入していた。現在の依頼と過去のユーザー発言の関連性で完了ターンを選ぶ。短いコンテクストでも選別を省略しない。明示的な継続指示は直前の完了ターンを参照する。 |
| プロンプトが23k〜26k文字規模になる | 通常RAGの設定外でWeb・APIの情報を固定長で詰めていた。共通の生成境界で追加情報を制限し、JSONを構造ごと縮めて部分取得を明記する。現在の依頼・出力形式・言語制約は切らない。複数APIのパケットは各プロバイダの次元を残して内部のサンプルや長文を縮める。 |
| 日本語の質問に英語資料を渡すと消える | 取得済みのWeb資料を履歴と同じ字面の選別にかけると、言語差で必要な資料を消してしまう。現在の検索で取得した資料は出所を持つ専用パケットとして渡し、履歴と区別する。予算は同じ共通境界で適用する。 |
| Kpの説明にCPIが出る | `compose_tool_result` の共通指示が常にCPIの注意書きを含んでいた。分野別指示を現在の依頼・現在のプロバイダに限定した。OLCR自身の説明も、「構成」「モデル」という一般語だけでは挿入しない。 |
| APIを組み合わせる依頼が単一APIで終わる | 50件中20件の依頼表現が従来の分析判定から漏れていた。「比較して」「あわせて」「横断して整理」など、複数の情報を結ぶ依頼を共通の分析経路へ送る。 |
| Laya/Brainで必要なソースが消える | 現在の依頼で明示されたAPIと、異なる節が求める補完ソースを保持する。単一分野向けの候補絞り込みでそれらを消さず、Brainの計画が一部を落としても必要なソースを取得対象へ戻す。旧ID・新IDの同一アダプタを重複実行しない。 |
| 複数APIを取っても一つの分析だけ返る | UCDP等の専用レンダラが、他のプロバイダの証拠がある場合にも先に終了していた。異なる種類の証拠があるときは共通の統合処理へ渡す。 |
| 同じAPI内で一つの指標しか取らない | World Bankの指標選択が排他的な分岐だった。GDP・失業率・インフレ率、再生可能電力・電力アクセス等を独立した必要指標として蓄積する。既存の複数指標取得アダプタを利用する。 |
| モデルの計画が対象国・期間・指標を変え得る | モデルが書いた取得方針は、元の依頼に新しい国・年・指標を追加する権限を持たない。引数コンパイラは現在のユーザー依頼をスコープの根拠にする。 |
| カナダの依頼に米国・日本の候補が残る | 国の候補フィルタにカナダがなく、「ラテンアメリカ」に米国の「アメリカ」が一致していた。国・地域の判別を修正した。 |
| 2025年の依頼に2026年のイベント、ラテンアメリカにアフリカのサンプル | 観測行に日付・地域があり、依頼との不一致が明確な場合は有効証拠として数えず、既存の回復経路へ送る。メタデータがないことを一致の証明にはしない。 |
| PDFのオブジェクト辞書が回答に出る | PDFのバイト列を通常テキストとして復号していた。本文を抽出できないPDFをWeb本文として渡さず、他のソースに回復する。 |
| embeddingの障害が会話メモリを止める | embedding失敗時には古いベクトルを流用せず、同じスコープ内で関連する完了ターンを字面で検索する。Graphifyも既存の検証済みソース・字面の縮退経路を維持する。 |

World Bankの追加指標は公式メタデータを確認した：[消費者物価の年率変化](https://data.worldbank.org/indicator/FP.CPI.TOTL.ZG)、[失業率（ILOモデル推計）](https://data.worldbank.org/indicator/SL.UEM.TOTL.ZS)。国別の年次統計と月次統計を同じものとして扱わない。

## 診断の訂正

元のGUI記録の `AUTONOMOUS_ANALYSIS_SEED_PRESERVED` は、過去のターンからseedが流用されたこと自体の証拠ではなかった。`chat` は現在の依頼の決定的ルータ結果からseedを作る。ケース24・35等の「古いseedが残った」という推測は未確定と訂正する。確認できた主要原因は分析判定の漏れ、先に一致した一つのルートへの偏り、候補の絞り込みである。

ケース22のCPI混入も、履歴の意味的な混入と断定できない。共通の生成指示に常時CPIが入っていたことが確認できた。履歴選別と分野別指示の両方を修正した。
