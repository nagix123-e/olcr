# チャットから使う個人アシスタント

通常のチャットで依頼すると、聞き取り・内容の確認・実行結果が同じ会話に表示されます。設定画面へ移動してタスクやフォーム、ツールを起動する必要はありません。

| 操作 | 指示例 |
| --- | --- |
| リマインダー | 毎朝9時に水を飲むようリマインドして |
| 定期的なメール確認 | 毎朝9時にGmailのメールから締切を確認するタスクを作って |
| メール作成・送信 | friend@example.org 宛てに、私のアップルのメアドから、京都での旅行の予定をどうするか尋ねるメールを出して |
| タスク一覧と停止 | タスク一覧を見せて / 「水を飲む」のタスクを止めて |
| 目標 | 目標を追加して。今月は本を10冊読む |
| プロフィール | プロフィールに、辛いものが苦手と登録して |
| ツール作成 | 入力した文字列を小文字にする再利用ツールを作って |
| ツール実行 | 小文字化ツールに HELLO を渡して実行して |
| フォーム入力 | https://example.org/contact のフォームの「件名」に「問い合わせ」と入力して |
| 通知・実行結果 | タスクのお知らせを見せて |
| 締切を予定案にする | 締切候補1を予定に入れて |
| 記憶の切替 | プロジェクトをまたぐ記憶をオフにして |
| 記憶の関連度 | 記憶の関連度の閾値を0.8にして |
| 通販への接続 | Amazonに接続して |
| 外部アクセス | 外部アクセスをオンにして |

必要な日時・対象・入力値が不足している場合は、同じチャットで質問します。候補が複数あれば名前やIDで選べます。確認前に「やっぱり毎朝8時にして」のように変更できます。

確認カードの「この内容で実行」、または確認直後の「はい」「その内容でお願い」で適用します。「キャンセル」で取り消します。設定の変更や一覧表示など、その場で完了できる操作もあります。保存済みの記憶はOFFでも削除しません。フォームの入力・ツールの保存や実行・タスク等の変更は、提示された内容を確認してから実行します。

確認内容と聞き取り中の状態は会話ごとに保存します。別の会話の確認や、変更前の古い確認ボタンでは実行できません。一般の確認は30分、フォームは既存仕様の5分で期限切れになります。二重送信や古い確認の再実行を防ぎます。会話を編集して巻き戻した場合、残っている会話に対応する状態だけを参照します。実際のサービス操作は巻き戻しで取り消されません。

タスクからの通知をチャットで開き、メール由来の締切候補を選ぶと、会話内にカレンダーの確認カードを出します。メールの内容から予定を自動登録したり送信したりはしません。

明示的なメール送信の依頼には、チャット内で送信元サービス・宛先・件名・本文を確認するカードを出します。「この内容で送信」または確認直後の「送信して」で、その確認内容を一度だけ送ります。宛先アドレスはユーザーが指定したものを使い、不足があれば聞き返します。サービス未指定で、接続済みの送信サービスが複数あれば選択を求めます。本文末尾にはAI送信の注記が付きます。Apple MailはMailアプリの既定の送信アカウントを使い、カードにもその旨を示します。チャット経由の送信元アドレス指定・CC/BCC・添付・予約送信は未対応のため、その依頼は実行せずに案内します。送信結果が不明な場合は自動で再送しません。

定期タスクにはバックグラウンドの許可が必要です。必要な権限を確認内容に示し、承認後に適用します。外部アクセスやメールの認証が不足している場合は、その旨をチャットで案内します。認証情報をチャットへ入力しないでください。通販サイトのログイン・認証は専用ブラウザーで行います。

フォームは公開HTTPSページの対応する文字入力欄を対象にします。ユーザーが指定した文字列を、観測済みの項目名に対応付けます。既存の権限、対象ページ・ブラウザープロセス・項目の再確認、期限、一度限りの確認を維持します。送信、購入、予約の確定は行いません。

入力の解釈やツール案の作成には設定済みの通常会話モデルを使います。タスク一覧、目標一覧、プロフィール表示、名前が一意なタスクの停止・一時停止・再開は、モデルに接続できない場合にも利用できます。実モデルや外部サイトに対する成功率は別途確認が必要です。
