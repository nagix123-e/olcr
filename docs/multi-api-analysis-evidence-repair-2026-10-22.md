# 同一会話API分析で判明した共通不具合の修正

ユーザーの指示により、r05の全件再実行を停止して修正を優先した。r04は50件実施済み。r05では43–50および1–3の計11件のGUI回答完了を確認し、4を送信したところで実行方針を変更した。4の最終GUI完了と5–42は合格判定していない。

今回の変更後の50件GUI E2Eは実施していない。以下はソース修正と回帰テストの記録である。

## 判断の限界

外部APIの認証・レート制限・停止、元のアダプターが未対応のデータ範囲、生物種や薬剤など未指定の識別子まで取得成功に変える修正ではない。取得できた範囲と不足を正しく保持して回復する。新しい主題検査は双方向の言語表現と本文の語彙を用いた保守的な検査であり、全ての任意の主題について意味的な完全性を保証するものではない。

r04/r05で観測した候補の誤採用・表示・カバレッジ・回復の原因に修正と回帰検証を入れた段階であり、変更後の全API実通信・GUI全50件を合格とは記録しない。
