## Source investigation correction (2026-10-21)

The earlier “stale seed” diagnoses in cases 24/35 are hypotheses, not proof of history reuse. Source inspection shows that `autonomous_seed_tool` is built from the current request's deterministic route. Missed analysis-intent recognition and first-match/single-provider narrowing explain much of the observed routing. Likewise, the case 22 Kp answer's CPI wording was also induced by an unconditional CPI instruction in the shared provider composer; it does not by itself prove prior-turn semantic carryover. Both the instruction scope and same-conversation relevance selection have now been repaired. See [repair and regression record](rag-api-routing-repair-2026-10-21.md). No post-repair GUI success is claimed by this original run.
