## 共通処理

- API streamingの約100行の重複実行/回復処理をchatへ集約。応答とtaskを送信前に保存。
- GUI streamはdone/error/cancelledで読み取りを終了し、EOF待ちによりローダーが残らない。中途切断とUIハンドラ例外も報告。
- モデル合成の期限は比較180秒、失敗したAPIの代替合成60秒。MLXはsubprocess timeoutでworkerを停止し、後続の通常生成へ期限を持ち越さない。
