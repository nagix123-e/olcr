## 共通修正

- APIの数値・進化条件・制裁登録・潮汐等は、既存の型付き表示で値を確定し、LLMによる再解釈で事実を書き換えない。
- 自動Web回復でBraveを強制せず、設定済みのBrave/Tavilyを既存の権限範囲で選ぶ。キーそのものは作成・表示していない。
- 説明に実行日時と設定された回答言語を渡す。過去のイベント、APIドキュメント、サンプル出力を現在の実データと取り違えないよう指示する。
- nullを省略と混同せず、比較する複数レコードへ根拠の文字数予算を配分する。省略・サンプル取得を明示し、完全な集計と主張しない。
- 代替ソースも取得に失敗した場合、「切り替えて確認できた」と表示しない。
