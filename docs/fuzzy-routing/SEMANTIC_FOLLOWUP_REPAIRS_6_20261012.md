# 12件E2Eで残った6件への修正（2026-10-12）

対象はPARTIALの90・142・316とFAILの27・42・97です。既存のadapter、共通renderer、失敗回復処理の内部で修正しました。過去のE2E判定は変更していません。

| ケース | 修正 |
|---|---|
| 27 / 97 | MLX合成期限超過後に返された取得済み抜粋・出典を、外側の失敗処理が一般エラーで上書きしない。未完了の説明と根拠を保存し、元APIエラーとfailed状態を維持。 |
| 42 | 共通の型付き表示で流量・観測時刻・測定項目を表示し、ft³/s→m³/sを算術変換。Pは暫定値として表示し、モデルによる単位・品質コードの再解釈を回避。 |
| 90 | 映画好き向けは上級を要求して返却難度を検証。問題・選択肢を既存MyMemory APIで翻訳し、設定の応答言語を尊重。正解の識別情報は翻訳へ渡さず、翻訳失敗時は未完了を説明。 |
| 142 | 現在の東南アジア質問ではopenかつ直近30日以内の観測を持つ候補を表示。終了済み・古い観測のみ・未来の日付を除外。初回/最新観測、確認元URL、除外数を示し、災害の実際の開始日・継続を断定しない。 |
| 316 | 本文APIの認証失敗後に同じCourtListenerの公開判決ページを取得。本文コンテナだけを抽出し、メニュー・scriptは本文にしない。取得元を保存し、本文が依然取得不能なら検索抜粋と未確認項目を明示。 |

USGS品質コードは[公式仕様](https://waterservices.usgs.gov/docs/dv-service/daily-values-service-details/)、EONETのopen・日付・観測は[公式v3仕様](https://eonet.gsfc.nasa.gov/docs/v3)で確認しました。最近の観測だけに絞る30日窓はアプリの候補選別方針であり、古い登録を災害終了と判定するものではありません。

オフライン回帰確認60件（37＋23）、Python構文確認、差分の空白確認を通過しました。ログ・SHA256・今回の差分は[JSON台帳](SEMANTIC_FOLLOWUP_REPAIRS_6_20261012.json)に保存しました。
