# 修正後の実GUI E2E（2026-10-12）

28件E2E後の修正対象11件と、追加補修したケース47を、署名済み隔離アプリでGUIから再実行しました。12件すべてを送信し、ケース107→108は同じ会話の連続質問です。日本語は各送信前に入力欄の値を照合しました。

## 結果

| PASS | 6 | 24, 47, 59, 107, 108, 124 |

ケース24はISSの概略海域を表示、47はGBIFの5行すべてに日付・学名・座標を表示、59はインスリン前駆体/成熟領域を表示、107/108は棋譜・短長比較を表示、124は移動手段の確認まで完了しました。クイズ90は正答を隠しましたが、回答言語と難度が依頼に合いませんでした。

ケース27（NASA/Exoplanet）と97（Met）は、Web検索結果をそれぞれ10件・8件取得したものの、MLX合成が約60秒で停止し、根拠を回答に含められず一般的なエラーだけを表示しました。タスクはfailedへ終端し、GUIの生成表示は消えました。ケース42（USGS）は回答を終端しましたが、7,660 ft³/sを約217,000 m³/sと誤換算し、qualifier `P`も水位コードと誤解しています。

ケース142はEONET 55件から型付き回答を出しましたが、依頼の「進行中」を十分に確かめず古い観測も含みます。ケース316はCourtListenerの本文401を明記し、候補の本文・争点・関連性を確認できていないと伝えました。両方とも部分達成と判定しました。

遅いケース27・42・97でも、GUIローダーは約65〜67秒で終端応答に移った後に消えました。ほかの9ケースも終端UI状態を確認しました。
