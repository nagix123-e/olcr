# プロジェクト・会話のピン留め

各行に共通のピンボタンを追加。ピン留めは先頭グループに並べ、グループ内は従来の更新日時順を維持する。解除時も更新順に戻る。ピン操作はupdated_atを変更しない。「プロジェクトなし」は従来のナビゲーションとして残す。

- SQLite v35→v36でprojects/conversationsにpinned列を追加。既存行は解除状態。新規作成・エージェント会話作成は明示的な列名によるINSERTへ変更し、通常の作成経路を維持。
- 専用PUT APIで明示的なtrue/falseを保存する。会話のプロジェクト条件をUPDATEと同じSQLで検証し、他プロジェクトやプロジェクトなしの会話へ越境できない。
- フロント側でも同じ順序で並べ、保存完了時に対象行だけ更新する。選択中の会話・本文・下書きには触れない。保存中は該当ボタンを無効化し、失敗時は元の表示を保持する。
- 共有UiIconの24px/currentColorのピンを使用。押下状態を塗りと背景、aria-pressed、解除ラベルで伝える。30pxの操作列をピンと削除にそれぞれ確保。既存のワークスペース割り当てと内側スクロールを維持する。
