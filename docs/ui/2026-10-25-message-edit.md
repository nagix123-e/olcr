# 送信済みメッセージの編集・再送

現在の編集UIは[通常入力欄での編集](2026-10-25-composer-edit.md)へ更新済み。以下は初回実装時の検証記録。
対象は保存済みの直近2件のユーザーメッセージ。共通UiIconのedit（鉛筆）を入口、refresh（循環矢印）を再送に使う。元のメッセージの位置に本文編集欄を開き、キャンセル・Escapeでは変更を送らない。

「保存して再送」は、対象メッセージとそれ以降のユーザー・アシスタントの会話を削除してから、通常の送信・振り分け経路で実行する。通常会話・カスタムエージェントの結び付き・概念図を引き継ぐ。添付は保存済み履歴に元データが残らないため、編集欄で再選択する。選択しない場合は本文だけ再送する旨を表示する。

## 履歴・実行の扱い

- 会話ID・プロジェクトID・対象メッセージID・読み込んだ履歴末尾IDを検証。別会話・古い履歴・直近2件以外は変更しない。
- 実行中の通常タスク・コーディングタスクは停止してから再送する。実行中のComputer Useも再送前に停止が必要。
- 旧タスクの実行記録を残し、置き換えられたタスクの再開対象化・遅れて届く停止メッセージを抑止する。元のカスタムエージェント定義は保持する。
- 会話記憶のバックグラウンド登録時も現行の発言と回答を照合し、削除済みの回答の再登録を防ぐ。
- 競合・通信失敗では編集本文を失わない。履歴変更の競合が起きた場合は新しい実行を開始しない。
- 実行済みのファイル変更・外部操作などは巻き戻さない。この点を編集欄に表示する。
