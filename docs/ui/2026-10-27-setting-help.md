# 設定項目の補足ツールチップ

分かりづらい設定に、共通の `SettingHelp` を追加した。対象は音声入力の方式、外部アクセス、MCP、追加機能の実行環境、YaRN・圧縮・オーケストレーターなどの機能、Gitの自律実行、検索プロバイダーと検索モード、Brainとフォールバック、コンテキスト・RAG、用途別モデル、APIベースURL・モデルID・OAuthスコープ。

14pxの丸付き「？」を既存の `UiIcon` に追加。既存の副次テキスト色、1.5pxの線幅、28pxの操作領域を使い、タッチ環境では操作領域だけ44pxとする。重要な権限・ダウンロード・保存条件の説明は本文にも残す。

ホバーは250msで表示。説明へポインターを移しても読み続けられる。フォーカスでは即表示し、クリック・タップでも開閉できる。Esc、外側のクリック、ウィンドウのフォーカス離脱で閉じる。同時に開く説明は1つ。`aria-describedby` と `role="tooltip"` を使い、設定のラベルとヘルプボタンは別要素にして、説明を開いても設定やフォーム送信を動かさない。

ツールチップはbodyへportal表示し、スクロール領域の切り取りを回避する。上下の空きと画面端に応じて位置を調整し、スクロール・リサイズ・説明サイズの変化に追従する。日本語・英語を用意した。
